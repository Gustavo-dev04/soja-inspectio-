--------------------------------------------------------------------------------
 7b. PRIMEIRA VEZ COM A CÂMERA CSI (IMX219)
--------------------------------------------------------------------------------

 !! DESLIGUE A JETSON ANTES DE PLUGAR O CABO !!
    Plugar com a placa ligada pode queimar o sensor.

 Orientação do flat:
   - lado da Jetson : contatos metálicos virados para o DISSIPADOR
   - lado da câmera : contatos virados para BAIXO (lado da PCB)
   - trava do conector puxada antes de inserir, empurrada depois
   - conector de 22 pinos (o de 15 é do Jetson Nano antigo, não serve)

# diagnostica cabo, kernel, driver, GStreamer e OpenCV, e salva uma foto
./setup_camera.sh

# ver ao vivo (para enquadrar e ajustar o foco da lente)
./setup_camera.sh --ver

# --- nenhum /dev/video* ---
# O LED do módulo indica se ele tem energia. Isso separa os dois casos:
#
#   LED ACESO   -> cabo OK; é DEVICE TREE (o Orin Nano Dev Kit vem sem
#                  nenhuma câmera habilitada). Este é o caso comum.
#   LED APAGADO -> é físico; replugue com a placa DESLIGADA

sudo dmesg | grep -i -E 'imx219|nvcsi|vi5' | tail -20
grep -i overlays /boot/extlinux/extlinux.conf
ls /boot/*.dtbo 2>/dev/null | grep -i -E 'camera|imx'

# habilitar o IMX219 no device tree
#
# O jetson-io NAO funciona no JetPack 6/7 (quebra com "No DTB found", porque o
# DTB base passou a vir da partição e não do /boot). E só acrescentar OVERLAYS
# no extlinux.conf não basta: o bootloader aplica ou descarta em silêncio.
#
# Use o script, que mescla o overlay no DTB com fdtoverlay e CONFERE que o nó
# imx219 entrou ANTES de mexer no boot:

sudo ./habilitar_camera.sh              # IMX219 no CAM0
sudo ./habilitar_camera.sh imx219-C     # se a câmera estiver no CAM1
sudo reboot

# desfazer, se precisar
sudo ./habilitar_camera.sh --desfazer

# se o nvarguscamerasrc não abrir
sudo systemctl restart nvargus-daemon && sleep 2
